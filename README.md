# Разбор партий

Программа для разбора шахматных партий с chess.com, решения задач, игры с ботами и изучения дебютов. Работает на **macOS (Apple Silicon)** и **Windows 10/11**. Всё нужное, включая движок Stockfish, база дебютов и 83 тысячи задач, уже внутри: ничего докачивать не надо.

## Как скачать готовую программу

Откройте страницу **Releases** этого репозитория (справа на главной странице) и скачайте файл для своей системы:

| Система | Файл |
|---|---|
| Mac с чипом Apple (M1–M4, A18) | `RazborPartiy-…-mac-arm64.dmg` |
| Windows, установщик | `RazborPartiy-Setup-…-win-x64.exe` |
| Windows без установки | `RazborPartiy-Portable-…-win-x64.exe` |

**Mac.** Откройте `.dmg` и перетащите «Разбор партий» в «Программы». Программа не подписана сертификатом Apple, поэтому при первом запуске нажмите на ней правой кнопкой → «Открыть». Если macOS всё равно не пускает: «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть». Если пишет, что приложение «повреждено», выполните в Терминале:

```bash
xattr -cr "/Applications/RazborPartiy.app"
```

**Windows.** Запустите установщик или переносную версию. Если появится синее окно SmartScreen («Windows защитила компьютер») — нажмите «Подробнее» → «Выполнить в любом случае». Так бывает со всеми программами без платного сертификата.

## Что умеет

- **Разбор партий** как на chess.com: классы ходов (блестящий, лучший, ошибка, зевок…), точность, примерный рейтинг игры, объяснение каждой ошибки по-русски, ключевые моменты и итог партии. Анализ идёт параллельно на всех ядрах процессора; глубину можно выбрать: «Быстро», «Обычно» или «Точно».
- **Импорт** последних партий с chess.com по нику, автоотслеживание новых партий, вставка PGN/FEN/ссылки.
- **Задачи**: 83 тысячи задач из открытой базы lichess. Разделы: по уровню (от новичка до мастера), маты в 1, 2, 3, 4 и 5+ ходов, дебют, миттельшпиль, все виды эндшпиля, 30 тактических приёмов, задачи по длине решения. Отдельно — «Композиции и классика»: этюды, ловушки и знаменитые комбинации, проверенные Stockfish. Ведётся рейтинг решения и серия.
- **Игра с ботом**: Stockfish с 20 уровнями силы (примерно от 400 до 3100 Эло), с часами или без, подсказки, ход назад, ничья, сдача и разбор партии в один клик.
- **Курс дебютов** для начинающих: какие дебюты учить и в каком порядке. В каждой главе теория, варианты с пояснениями к ходам, тренировка с подсказками и экзамен: варианты по памяти и вопросы по идеям. Зачёт ставится от 80%.
- **Дебюты**: 3 865 вариантов lichess, разделённые на «Дебюты», «Начала» (системы первого хода: 1.c4, 1.f4, 1.b3…) и «Редкие»; гайды для 91 семейства с ловушками.
- **Тренажёр**: интервальное повторение дебютов и задач из собственных ошибок.
- **Статистика**, **свободный анализ**, экспорт PGN и PNG, AI-тренер по желанию.

## Сборка из исходников

Нужен Node.js 22 или новее. Всё остальное, включая Stockfish, уже в репозитории.

```bash
npm install
npm run dev          # запуск в режиме разработки
npm run dist:mac     # .dmg и .zip для Mac (собирать на Mac)
npm run dist:win     # установщик и переносная версия для Windows (собирать на Windows)
```

Готовые файлы появятся в папке `dist/`. Удобнее не собирать вручную: при публикации тега `v*` GitHub Actions сам соберёт обе версии и выложит их в Releases (`.github/workflows/release.yml`).

| Команда | Что делает |
|---|---|
| `npm test` | тесты (vitest) |
| `npm run typecheck` | проверка типов |
| `npm run verify:guides` | проверка ловушек в гайдах дебютов через Stockfish |
| `npm run verify:course` | проверка всех ходов курса дебютов через Stockfish (отчёт — `docs/course-verification.txt`) |
| `npm run build:compositions` | сборка и проверка композиций (отчёт — `docs/compositions-verification.txt`) |

## Примечания

- Программа не читает доску с экрана и не подсказывает в идущих партиях: chess.com отдаёт через API только завершённые партии.
- Сеть: только `api.chess.com` и, если включён AI-тренер, `api.anthropic.com`.
- Внутри пакета для Mac приложение называется `RazborPartiy.app`, а Finder и Dock показывают «Разбор партий». Латиница в именах файлов нужна, иначе Electron падает при запуске из-за буквы «й».
- В репозитории лежит Stockfish 17.1: файлы Stockfish 18 больше 100 МБ, и GitHub их не принимает.
